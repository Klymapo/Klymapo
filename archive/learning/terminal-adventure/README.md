# Terminal Adventure ⚔️

Pequeño **RPG narrativo para terminal**, creado como proyecto de aprendizaje de Python. Las decisiones del jugador modifican algunos resultados de la aventura; incluye creación de personaje, atributos, tienda y tiradas.

## Cómo ejecutarlo

Con Python 3 instalado:

```sh
python main.py
```

Ejecuta el comando desde la carpeta del repositorio para que Python encuentre los módulos locales.

## Archivos principales

| Archivo | Función |
| --- | --- |
| `main.py` | Inicio y flujo de la aventura. |
| `Character_Creation.py` | Creación y atributos del personaje. |
| `Texts.py` | Narración y textos. |
| `Shop.py` | Tienda y compras. |
| `ALTERNATIVE1.py` y `Desicion_1.py` | Lógica de decisiones y alternativas. |

## Estado

**Archivo de aprendizaje.** Se conserva tal cual como parte de mi evolución programando. Puede contener limitaciones, errores de redacción en inglés y decisiones técnicas propias de un primer prototipo; no se presenta como un juego terminado.
