# Dungeon Meshi Delivery Service 🍲

Sitio web experimental inspirado en *Dungeon Meshi*, realizado como ejercicio de aprendizaje de HTML, CSS y desarrollo web.

## Contenido

- `main`: archivo fuente de la página. **No tiene extensión `.html`** en este repositorio; esto puede afectar la publicación automática en alojamientos estáticos.
- `README.md`: notas del proyecto.

Para probarlo localmente, descarga una copia de `main`, guárdala con nombre `main.html` y ábrela en el navegador. No se ha verificado aquí un despliegue público de esta página.

## Estado

**Proyecto histórico de aprendizaje.** Se mantiene como muestra de mis primeros experimentos web. Una eventual versión nueva debería tener `index.html`, recursos propios y documentación de publicación, pero no se cambia el archivo original en esta reorganización.

Gracias a **Codédex** y **Mimo** por acompañar mi aprendizaje.
